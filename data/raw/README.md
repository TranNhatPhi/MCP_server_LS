# data/raw — file gốc, CHỈ ĐỌC

Đặt vào đây tech pack, BOM, file khảo sát, file xuất từ ERP.

`SafeWriter` không bao giờ ghi vào thư mục này: `write_roots` chỉ gồm `work/`,
`out/` và `state/`. File gốc của khách và của merchandiser không bị máy đụng vào.

Nội dung thư mục này không vào git (xem `.gitignore`) vì phần lớn là tài liệu
khách thuộc vùng Z3 — NDA.
